🐍 My Python Journey: Fundamentals to Management Systems

Welcome to my Python learning repository! This project documents my complete progress in Python—from mastering core fundamentals and intermediate data structures to building real-world management systems.

🚀 Projects Overview

Each project in the projects/ directory is designed to simulate a real-world software system using Object-Oriented Programming (OOP), file persistence, and robust input validation:

🏦 Bank Management System

Manages user accounts, deposit/withdrawal calculations, and balance inquiries.

Includes error handling for insufficient funds and invalid inputs.

📚 Library Management System

Tracks book availability, member registration, and book issuing/returns.

Implements real-time catalog search and updates.

💼 Payroll System

Calculates gross and net salary based on hourly rates, bonuses, and tax deductions.

Generates formatted pay slips for employees.

🎓 Student Management System

Handles student enrollment, course registration, marks entry, and automated GPA calculation.

🛠️ How to Run

Clone this repository:

git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

python basics/01_variables.py

# Run a project
python projects/bank_system/main.py
